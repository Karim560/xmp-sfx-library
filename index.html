التثبيت في دقيقة

  1. نزّل ملف XMP-SFX-Setup.exe واضغط عليه مرتين.
  2. لو ظهر تحذير ويندوز الأزرق، اضغط More info ثم Run anyway.
  3. اقفل بريمير أو أفتر إفكتس لو مفتوح، وكمل التثبيت.
  4. افتح اللوحة من Window › Extensions › XMP SFX
  5. الصق كود التفعيل — مرة واحدة وخلاص.
